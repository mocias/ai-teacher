# V0.5 学习闭环版

发布日期：2026-10-19。范围：资料 → 目标 → 能力与诊断 → 路线 → 每日学习 → 考察与复习。

## 从哪里开始

1. 在资料库导入资料，或从内嵌阅读器继续阅读。
2. 点击“用于正式学习”，选择已有目标或填写新目标，并指定主材料、补充材料或参考资料。确认后使用原资料记录，附件、正文版本、阅读位置和批注保留。已有正式目标的资料直接打开目标进度；跨目标的阅读关联继续使用原阅读器功能。
3. 在“学习管理 → 目标进度”按下一步继续：分析主材料、生成并确认能力要求、进行初始诊断、生成并确认路线。更改能力要求后，需要针对当前版本重新诊断和规划。
4. 点击“生成排期预览”，设置开始日期、学习日、每日预算与单项时长。检查预览后确认保存。只安排没有有效日程的待学习任务，按显式先修关系排序，并计入现有日程用时。预览本身不保存日程。
5. 从首页的每日任务打开资料、记录进度和笔记，再自愿开始学习考察。任务内可以安排一次复习，默认选中本任务关联的首项要求；仍可自行选择其他要求。
6. 首页提供到期和进行中复习的直接入口。回答后保存反馈和证据；最终综合面试通过并由用户确认后，目标才完成并保存结束快照。

## 状态与数据规则

- 目标进度优先显示当前考察和待处理请求，再按当前能力版本和路线决定下一步；暂停或已结束目标有单独入口。
- 排期时不会修改已有日程。取消后可以重新安排；已有后续任务排期早于新前置任务时，需先调整日期。同日新增任务按先修顺序追加，没有推测具体钟点或课时难度。
- 每日预算计入当天所有未取消日程，包括已经学完的日程。单个任务采用统一时长，保存后仍可在日历逐项调整。最多向后寻找一年。
- 预览包含当前路线、能力版本和日历的指纹；确认时重新校验。状态变化后拒绝旧预览，批量保存失败全部回滚，同一请求重试不重复创建。
- 资源关联和批量排期是用户会话操作；Agent 凭据不能调用这些确认接口。
- 阅读、日程进度、路线考察数量和回答证据分别展示。100% 学习进度不改变能力判断，也不会凭空生成证据。
- V0.5 没有新增数据库表；复用现有学习、资料、日历和阅读结构。新库的默认 Teacher 提示词已更新；已有自定义提示词保留。

## 打开新版

入口：`outputs/desktop-v0.5.0/AI Teacher-win32-x64/AI Teacher.exe`。关闭旧版应用和旧服务后打开。新版沿用原桌面应用的用户数据目录配置；没有移动、合并或复制正式学习库。原有 `dist`、先前独立包和桌面快捷方式保留，旧快捷方式不会自动指向新版。

此交付是免安装的 Windows x64 应用文件夹；尚未提供安装器、代码签名或自动更新。

## 接口

- `POST /api/resources/goal`：资料关联已有或新目标，需 `resource_id`、`role`、`request_id`，以及二选一的 `goal_id` / `goal`。
- `POST /api/calendar/preview`：输入 `goal_id`、`start_date`、`weekdays`、`daily_minutes`、`session_minutes`，返回预览、总分钟数与指纹。
- `POST /api/calendar/batch`：相同设置加 `fingerprint` 和 `request_id`，原子保存；预览已变化时返回 409。

完整结构见 `docs/openapi.json`。
