# 从讨论到正式路线

在 **Teacher 对话** 中可以直接讨论安排、回答问题或明确提出执行计划。比如先聊好七天的主题和每天可用的时间，再说“按刚才商量的推进”。Teacher 会沿用这段对话，结合当前目标进度，调用负责当前环节的功能。也可以展开对话里的“把这段讨论整理成学习路线”从当前讨论开始。

1. Teacher 先检查正式关联的主材料。如果范围与正文已经确认，它会读取相应版本并安排分析；缺少内容或范围时，工作台会提示需要补充什么。
2. 能力提案出现在原对话里，可以查看具体内容、确认、提出修改意见或暂缓。确认能力要求后，从这里开始正式初诊。已有当前版本的有效诊断时，可直接沿用。
3. 在诊断对话里回答问题。结束后，Teacher 会把实际结果、已确认的要求和原讨论结合起来，在原对话生成路线提案。可从诊断对话返回原规划。
4. 检查提案中的阶段和任务，点“确认并采用这份路线”后，正式学习任务才会建立。具体天数、主题和节奏取决于讨论内容与诊断结果。
5. 从学习路线打开具体任务，选择“进入学习答疑”，在该任务的独立对话中提问、讲解和练习。对话顶部显示任务目标，并可返回目标与规划。每个任务持续复用自己的学习记录，正式考察通过单独入口进行。

想修改能力要求或路线时，点击“我想调整”即可回到下方的主对话输入框，也可以直接输入修改意见。已有草稿继续保留。发送后，Teacher 结合当前提案和历史讨论继续交流，并在意见明确后生成新提案供确认。

目标与规划对话用于确定方向、范围和安排。任务学习对话使用对应任务、当前已确认的资料正文片段及路线来源作为上下文。学习期间的提问与练习只保存到该任务对话，掌握程度由正式考察产生的证据判断。

继续提问不会强制开始规划。已开始的流程可以用对话中的选项或明确的自然语言指令暂缓、恢复、修改当前提案。停止后，已经开始执行的一轮可能会先完成；已有工作和决定保留在原学习库中。执行出错时可查看本轮状态，再明确重试。

聊天连接需要支持工具调用，专业任务使用“模型与分工”里各自保存的配置。不支持工具的聊天连接仍可讨论，点对话里的整理入口也能启动流程。切换或刷新页面后，当前提案、初诊和来源对话仍然可查。
