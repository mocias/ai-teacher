# V0.8 逾期待办重新排期

日期：2026-10-20。本版让没有按时完成的路线学习、补学和独立日程可以一起重新安排，接着原来的进度继续。

## 使用

1. 首页“往期待办”中点击“预览并重新排期”。
2. 勾选待办，填写开始日期、每日分钟预算和学习日。
3. 预览原日期、新日期、进度和调整后的每日总安排。修改设置后需要重新预览；关闭窗口不保存。
4. 点击“确认调整日期”。任务会按新日期出现在首页和日历，原进度、笔记及资料关联保留。

## 规则

- 只移动所选的未完成、未取消、早于本地今天的日历任务，最多 100 项。复习日期在复习页单独处理。
- 已有未取消日程（包括当天已完成日程）计入每日预算。按原预计时长计算，不根据进度推算剩余时间。搜索范围为开始日期起 366 天。
- 保留原钟点；不自动检查具体时段重叠。仅改变日期和当天排序。
- 先修任务优先。如果遗漏尚未完成的逾期前置任务，或前置任务还未排期，会提示处理；固定未来前置任务之后的次日才安排所选后续任务。一起移动的前后任务可以在同一天按顺序学习。
- 不会自动移动未选中的未来任务；若新日期与其先修顺序冲突，会拒绝本次预览。
- 暂停或已结束目标、正在考察的任务、移出路线的任务、旧能力要求及已解决薄弱点的补学，会显示不能调整的原因。
- 预览后日历、进度、路线或相关学习状态有变化，需重新预览。确认在一个事务中完成，失败全部回滚；重复请求不重复写入。
- 不产生回答证据，不改变薄弱点、复习状态或目标完成状态。本版无需新增数据库表。

## 接口

新增用户会话接口 `POST /api/calendar/recovery-options`、`recovery-preview` 和 `recovery-commit`，Agent 凭据不能代替用户确认。参数与响应见 `openapi.json`；`as_of` 是浏览器本地日期，确认时跨日需重新打开窗口。
