# 自主阅读与整体画像

## 使用入口

- 阅读器是 AI Teacher 主窗口内的页面，保留侧边导航，不创建新窗口。
- 点击资料卡片、资料详情或任务关联资料 → 直接在阅读器中打开；导入 PDF/Markdown/PPT/PPTX 或网页后直接阅读。
- 同一资料重复打开复用标签；切换回资料库等页面保留标签和阅读位置，只在阅读器可见时记录活动资料的位置。
- 首页“继续阅读”显示最近三份已阅读资料、上次位置和时间，点击直接回到桌面阅读器。重新打开文件恢复 PDF 页码或 Markdown 章节；网页恢复保存的网址片段及匹配的章节标题。已有标签直接复用当前位置；网页标题变化或内容尚未加载时，可能需要手动定位。
- 阅读侧栏 → 选文提问、高亮、划线、笔记、关联目标。
- 阅读答疑遇到失败或未配置时，侧栏按问题显示处理状态，可就地重试、取消或进入“模型与分工”。重试沿用原问题与阅读快照，不新增重复问题；排队和执行中的问题都可取消，问题记录保留。进入配置后从左侧返回阅读器，保留标签、章节位置和未发送草稿；不同标签的处理状态分别显示。
- 学习画像 → 整体画像与首次引导；首页在首次使用或有待处理追问时显示入口。
- 学习路线 → 调整任务；目标选择处 → 修改目标；评估 → 修改要求；目标画像 → 修正目标画像。笔记和日历沿用原编辑入口。

## 阅读边界

网页使用独立的持久化浏览会话，可手动登录，网页无 Node 权限，也没有工作台桌面操作接口。只接受 HTTP/HTTPS 导航。各标签页独立，只有活动标签页的位置进入学习上下文，提问时冻结当前页 / 章节、选文和网址，避免随后切换污染已排队的问题。

PDF 使用 PDF.js；Markdown 使用 Marked + DOMPurify；PPT/PPTX 使用本机 PowerPoint（关闭宏执行、只读打开）或指定的 LibreOffice 转换，原附件不覆盖。转换缓存和阅读记录保存在所选数据目录的 SQLite。单文件沿用 20 MB 上限；转换后上限 100 MB。未安装转换器、加密或不支持的文件会报告失败，不声称已读。

没有 OCR、音视频转录、PPT 动画播放、外部浏览器监控、文件变更监控或网站内容更新检查。扫描件仍可浏览，无法提取正文时 AI 必须说明限制。网页提问读取普通 DOM 正文；跨域嵌入框架、画布文档和受保护阅读器不保证可提取。网址支持不等于所有站点都允许嵌入式浏览器登录。

网页以去掉片段的规范 URL 对应资料；同一个资料 ID 的阅读位置在多个目标间共享，链接跳转到其他 URL 时对应另一个资料。文件上传副本不随原文件更新。高亮/划线保留选文和位置，页面文字不再匹配时仍可在侧栏查看原标记。

## AI 与确认

READING、ONBOARDING、CHANGE_REVIEW 是无目标对话，旧路由下复用普通对话的 API / 宿主队列；启用独立功能配置后，分别直接进入 reading / onboarding / change_review 的 API 或 MCP 入口，不经过主 Agent。阅读只开放上下文读取和回复；另外两类按用途开放画像提案、修改判断、原因记录。AI 没有确认接口。

首次引导的固定提示不开放编辑。已有目标、资料、笔记或消息的数据目录视为已有用户。新用户可以跳过、恢复，已确认后结束首次引导。草案只通过继续对话修正，确认须匹配整体画像版本，并等待当前对话处理完成。

连续手动修改在 30 秒静默后合并提交 AI。30 秒用于结束这一轮编辑，不用于判断修改大小。AI 根据语义决定是否追问；措辞调整可以无需追问。用户跳过会取消该次待处理任务及其未确认建议。临时原因不改整体画像；长期偏好必须另行确认。没有可用模型时，消息保留在队列，沿用模型配置、重试和取消机制。

能力要求编辑创建新版本，保留旧定义与旧证据。已结束目标及已经开始的路线任务不可被此编辑入口重写。阅读、批注、首次自述和修改解释不会产生掌握证据。

## 保存与验证

首次升级前创建 `backups/before-study-*.sqlite`。完整数据库备份包含原附件、转换缓存、阅读快照、批注与画像建议。JSON 导出并非完整附件备份。

- `node --test tests/*.test.mjs`：原流程回归，独立阅读、跨目标进度、确认与修正、语义追问、临时原因、快照隔离、迁移和 HTTP 权限。
- `node scripts/check.mjs`：语法与资产检查。
- `node scripts/smoke-desktop.mjs --reader`：独立临时数据下的实际桌面阅读、网页、多标签、笔记、问题保存、首次配置引导；本机模拟模型额外验证阅读答疑失败后重试、无重复提问、排队/执行中取消、迟到回复丢弃、配置往返草稿保留及标签隔离。不调用真实收费模型。
- 设置 `TEACHER_PPT_FIXTURES` 指向包含 `sample.pdf`、`sample.ppt`、`sample.pptx`（正文含 `Slide sample`）的目录，可额外验证三种文件的实际显示与文字提取。

AI 工作流用模拟模型验证工具调用、保存、权限和确认，没有冒充真实模型教学质量测评。桌面实测使用自制样例，不覆盖全部网页登录提供方和全部复杂演示文稿。
