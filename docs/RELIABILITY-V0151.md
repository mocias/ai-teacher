# V0.15.1 输入稳定性与后端可靠性

更新日期：2026-11-04（Asia/Shanghai）。

## 修复原因和行为

目标讨论页自动保存草稿后刷新工作台，会替换正在编辑的 textarea。恢复焦点和文字不能恢复 Chromium 的中文组合输入。桌面回归在修改前通过原生 IME 接口复现输入框脱离文档；修复保留编辑器和祖先节点，更新周围内容。回复继续显示，中文组合输入、选区和撤销历史得以保留。发送过程中新输入的草稿保留，失败可重试，切换讨论后旧请求不会把页面切回去。所有对话使用共用的 Enter/IME 判断。

后台维护只通知该次操作实际产生的业务变化，续租本身不再触发工作台全量刷新。读取状态时如果恢复了过期任务，也会通知其他打开的页面。

自动执行任务过期时先阻止自动重发，再释放领取状态。API、Codex 和其他自动宿主的未完成调用需要明确重试；手动 MCP 仍可重新领取正常过期任务。恢复时拒绝迟到回复，已完成和已取消的任务保持原状态。启动恢复同样先设置阻止标记，避免恢复过程中再次退出导致重复执行。

材料分析和补学选材使用每个目标的正式材料关联。共享给另一个目标的材料可用，材料分析仍要求该目标已确认的范围和正文版本；未关联或过期版本不能绕过校验。

全局资料汇总改为批量查询，保留逐目标的范围、正文、角色和分析归属。局部读取的权限边界不变，不新增结果缓存。
