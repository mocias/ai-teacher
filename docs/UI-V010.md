# V0.10.0 聊天界面优化

主 Agent 改为固定视口聊天页：消息区独立滚动，输入框始终在页底。区分用户和助手消息，提供空白页建议、执行/失败/重试状态、会话信息、返回配置入口及窄窗口布局。

主 Agent、Teacher、目标讨论、个人画像、阅读答疑共用 Markdown 渲染，支持标题、加粗、列表、引用、表格和代码块。用户输入按原文显示。助手内容经过 DOMPurify 清理，不加载回复中的图片，不允许脚本、事件属性、样式或任意类名；代码块和宽表格内部滚动。

主 Agent 的草稿按站内对话 ID 保存在浏览器本机存储；刷新后恢复，发送失败不清除。Enter 发送，Shift+Enter 换行，中文输入法组词不触发发送。新回复只在读到末尾时跟随，阅读旧消息时保留位置，可点击“查看最新消息”。首页目标讨论在输入框聚焦时仍可更新回复，同时保留草稿、焦点和选区。

## DSH 的实际可见性

当前仍通过独立 headless 进程执行。所有 AI Teacher 对话共用 `ai-teacher-workspace`，每段对话继续复用自己的真实 session ID。原生日志和检查点留在当前学习数据目录下的 `dsh-runtime`。这些日志未注册到 DSH Desktop 的原生持久化和工作区目录，因此 **不会自动出现在 DSH Desktop 列表中**；这不是列表刷新延迟。

本版在主 Agent 的“会话信息”和“模型与分工”中明确显示该执行方式与可见性限制，不生成假桌面会话。收到 DSH 的原生 session 事件后立即通知站内 UI 更新映射，无需等模型首次工具回写。共享工作区、对话映射和恢复流程保持 V0.9.1 的实现。DSH Desktop 原生列表同步尚未实现。

## 验证

- `npm test`：现有业务和会话恢复测试。
- `npm run build`：所有服务器、前端、桌面与脚本语法。
- `node scripts/smoke-desktop.mjs --chat-ui`：真实 Electron、HTTP 与 MCP 回写；验证 Markdown、安全清理、固定输入框、窄窗口、草稿恢复、失败保留、后台更新的滚动定位，以及输入中仍刷新首页回复。
- `TEACHER_PACKAGE_DIR=... node scripts/smoke-desktop.mjs --packaged --chat-ui`：对打包成品执行上述验收。
- `node scripts/smoke-dsh-local.mjs`：真实本机 DSH 与本地模拟模型验证会话续接；不消耗云端模型额度。
