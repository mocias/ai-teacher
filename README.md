# AI Teacher · 本地学习工作台

## 下载使用（Windows）

当前版本 **v0.18.0 预发布版**，源码和 Windows x64 免安装包均公开提供。

1. [下载 Windows x64 压缩包](https://github.com/mocias/ai-teacher/releases/download/v0.18.0/ai-teacher-v0.18.0-windows-x64.zip)，或到 [v0.18.0 发布页](https://github.com/mocias/ai-teacher/releases/tag/v0.18.0) 查看更新与校验文件。普通使用者选择 `windows-x64.zip`，无需下载 Source code。
2. **完整解压**，打开 `AI Teacher-win32-x64` 文件夹，双击 `AI Teacher.exe`。保留整个文件夹；不要直接在压缩包里运行，也不要只复制 EXE。
3. 打开「模型与分工」，配置自己的模型 API 地址、模型 ID 和 Key；也可选用已安装并配置好的 DSH、Codex 或 Claude Code。程序已内置 Electron 和 Node，无需另外安装 Node.js；不附带模型账号或额度。
4. 在首页介绍自己的情况、讨论学习目标，再按提示确认学习方案。

学习数据默认保存在 `%APPDATA%\AI Teacher\data`。升级前退出旧版并备份整个数据目录，解压新版到新文件夹后运行；自定义数据目录可在「AI Teacher → 桌面设置」中查看或选择。当前仅提供 Windows x64，尚无代码签名、安装向导和自动更新。详见 [桌面说明](docs/DESKTOP.md)。

V0.18.0 将 DSH 改为对话级常驻宿主：首次使用后保持进程，后续消息恢复会话并刷新本轮工具权限。未指定搜索服务且没有可用凭据时自动使用公开搜索；考察中的公开讲解通过独立工具发布，私有评价不再被当作用户已看过的教学内容。详见 [运行与反馈说明](docs/RUNTIME-V0180.md)。

V0.17.4 补充中性出题提示词：出题前检查后续小问、括号和反问是否泄露前一问的答案；需要依赖用户判断的推演，通常等用户回答后再追问。该偏好覆盖开放题与选择题，保留已知条件、提示教学和独立小问的灵活性，不增加程序硬校验。

V0.17.3 调整选择题教学提示词：选项优先简洁，通常在用户选择后再追问理由；答错时先了解思路，再针对误区讲解。该偏好由模型按情境运用，不新增程序校验或固定追问轮数。

V0.17.2 支持对话内点击选择题：单选点击即提交，多选勾选后提交；选择与原题一起保存，已答和过期题目不能重复作答。任务练习和正式考察继续使用各自原有反馈与证据规则。

V0.17.1 支持在目标讨论、规划和任务学习对话中拖入或选择附件，发送后保留文件与消息的关联。阅读器提供返回原任务、学习记录或资料库的入口；近期任务直接显示学习答疑按钮，队列调整按需展开。

V0.17.0 整理导航与信息层级：首页侧栏分为「今天」和「目标与日历」，对话列表按目标规划、任务学习、正式考察分组，阅读侧栏按「答疑、标记、目标」切换。已有功能规则、确认流程、代理和资料保存方式保持不变。

V0.16.5 支持独立收起左侧主导航和会话列表，记住布局偏好；聊天区域使用剩余窗口空间，正文和输入区加宽，标题与目标选择更紧凑。

V0.16.4 将阅读标记与提问引用分开。高亮、划线和笔记保存到资料；选文提问和右键提问将原文附到问题中。

V0.16.3 为已确认的学习任务提供独立答疑对话，并支持收起阅读器右侧栏。浏览器工具栏常驻显示当前网络方式。

V0.16.2 将能力要求与路线的调整统一接回主对话。点击「我想调整」后，直接在主输入框继续交流，Teacher 结合当前提案生成调整后的方案。

V0.16.1 修复内置阅读器打开网页后空白的问题。外部网页连接失败时，可在原标签页选择「阅读器使用本机代理并重试」。代理地址沿用「模型与分工 → DSH 联网」的本机设置。阅读器会记住选择，也可以随时切回系统网络。

V0.16.0 支持从目标对话直接制定学习路线。聊好方案后，说“按刚才商量的推进”，Teacher 会在原对话整理能力要求；你确认并完成初诊后，它会接着提出正式路线。待审提案可在对话中确认、要求修改或暂缓。[对话规划说明](docs/GUIDED-PLANNING.md)。

V0.15.1 修复中文输入和草稿稳定性、后台重复执行与共享资料归属，并优化资料汇总查询。[修复与验证记录](docs/RELIABILITY-V0151.md)。

AI Teacher 把目标讨论、资料阅读、学习路线、考察、复习和补学放在同一个本地工作台。学习记录保存在 SQLite 中；模型通过独立 API 连接或 Codex、Claude Code、DSH 宿主完成推理，服务端负责校验、持久化和用户确认。

**当前源码版本：V0.18.0。** 本仓库为公开仓库，配套 Windows 下载包见 [v0.18.0 Release](https://github.com/mocias/ai-teacher/releases/tag/v0.18.0)。也可从源码运行或自行打包。

维护交接见 [HANDOFF](docs/HANDOFF.md)，桌面使用与构建见 [DESKTOP](docs/DESKTOP.md)。

## 当前功能

| 功能 | 行为 |
| --- | --- |
| 目标讨论 | 从模糊想法整理可编辑草案，经用户确认后创建正式目标 |
| 资料与阅读 | 保存本地附件、链接和正文；桌面内阅读、批注、记录位置与按当前内容答疑 |
| 学习路线 | 能力要求、初始诊断、阶段和主题、显式先修关系，以及日历排期 |
| 考察与复习 | 结构化问答、回答证据、薄弱点、复习、强化与最终综合考察 |
| 进度与补学 | 保存学习进度、安排补学、预览并调整逾期待办；学习进度与能力证据分别记录 |
| 模型与分工 | 各功能独立配置 API 或宿主；主 Agent 可按要求直接设置各功能的宿主与已有模型连接 |
| 对话体验 | Markdown、表格、代码、复制回复、自动伸缩输入、草稿与阅读位置保留 |

### V0.15.0 长期学习、复习和排期

确认新目标的能力要求后，打开「学习管理 → 目标进度 → 查看其他目标的作答依据」。同领域内共享知识点的旧考察会列出当时的要求、题目、回答、反馈、开闭卷和日期，可回到完整原记录，也可直接开始针对当前要求的短测。每种证据关系各展示最近三条。未形成正式证据的对话和笔记不会出现在这里。

初始诊断、增量诊断和路线规划可以读取与当前要求匹配的历史节选。Teacher 可在路线中引用具体旧作答，说明为何省去重复学习或先做短测；用户确认后生效。有相反表现时，需先取得本目标新的支持性证据，才能据此省去重复学习。正式结项仍需本目标的综合考察。新目标也可显式引用另一领域已存在的知识点。整体画像页按领域、主题、知识点展示判断与原回答，支持带依据的画像整理，以及经用户确认的主题拆分或合并。节点自身保持稳定 ID；跨领域同名不会自动合并。

在「目标进度」可以请 Teacher 对照多份材料。覆盖图附带正文版本，影响某项要求的材料冲突要由用户选择采用的来源或解释差异。相应学习任务会等待裁决，其他主题和复习可以继续。

「学习路线」显示现在可以执行的近期任务、先修和受阻原因。延后任务、移除单课和排除整个主题分别处理。「学习管理 → 周复习」按自然周区分日历进度、实际回答和证据。可设置每周学习日、每日容量及领域优先级，预览日期和理由后再提交。滚动复习可自愿启用，后续安排保留每次考察的来源。

「评估」里的阶段自测先由用户写下已学范围，再经两次宽泛探问进入聚焦自测。开卷期间可检索可用笔记或资料中的原文并保存临时笔记。Teacher 可针对笔记提出验证邀请，由用户决定是否开始。最新一次最终面试提前结束、当前必要核心主题被排除或核心材料冲突待裁决时，都不能用旧成绩结项。

细分能力与验收路径见 [Canonical V1 实现与验收](docs/CANONICAL-V1-PROGRESS.md)。

### V0.14.3：对话反馈与联网

画像页及其他主要对话页统一 Enter 发送、Shift+Enter 换行与输入法边界。DSH 对话显示实际阶段和工具记录，支持刷新续接和取消反馈；不输出内部推理正文。开放 DSH 原生联网搜索和网页读取，并支持应用专属本机代理。搜索服务的凭据独立于 Qoder 等对话模型，错误会明确显示。详见 [V0.14.3](docs/FEEDBACK-WEB-V0143.md)。

### V0.14.2：主 Agent 直接设置与模型列表提速

可以直接告诉主 Agent“将各功能设置为 DSH”。它先读取配置，再调用 `teacher_set_agent_configuration`，成功后立即生效，不需要额外开关或设置页确认。变更记录保存在“模型与分工”，未被后续修改覆盖时可撤销。新建 API 连接和密钥仍使用原表单；能力、路线、长期画像等学习提案的确认流程不变。

模型列表先返回已验证的持久缓存，后台同步最新插件目录，更新通过现有 SSE 推送；配置变化使缓存失效，实际执行仍检查适配器。详见 [V0.14.2 说明](docs/DIRECT-CONFIG-V0142.md)。

### DSH 插件模型接入

主 Agent、目标讨论、Teacher 对话、画像对话和阅读答疑可以分别选择 DSH 模型；功能设置也可指定默认模型。模型选择按对话保存，对后续消息生效，已排队的显式选择不会被后续切换改写。

模型目录来自 **DSH 运行时注册表**，覆盖普通提供商和兼容的模型插件，包括 Qoder。发现与执行使用同一套插件来源，启动回合前验证提供商和模型是否就绪；插件缺失、停用、依赖不满足、目录读取失败或查询中途配置变化都会得到诊断，不静默改用另一模型。

查询合并并发请求、缓存 60 秒；配置变化会使缓存失效，刷新按钮可强制重查。Qoder 冷启动复用经过字段筛选的公开目录元数据，不复制登录凭据。目录查询不发送提示词，但插件可能联网同步模型目录。不同机器的模型数量取决于安装、配置和登录状态。

实现、兼容边界及验收见 [DSH 模型接入说明](docs/DSH-MODELS-V0141.md)。

### 对话界面、流式与加载

V0.14 统一了导航、消息排版和输入区，将模型选择与发送操作整合到输入框底部。侧栏显示当前服务版本，执行状态显示实际模型、已有工具调用次数和用时。

DSH 回复正文支持实时分片显示、刷新续接、取消和正式保存后的去重。V0.14.3 已接入实时工具开始／结果和生成阶段。完整内部推理正文不展示，进度记录目前仅在内存保留。

页面共享 SSE 连接，合并连续通知，只加载当前对话，避免无变化时重建内容；静态资源支持 ETag，Markdown 缓存保留安全清理。已验证的改善是请求与重绘减少，不代表云模型首字延迟或推理速度提升。

详见 [对话 UI](docs/CHAT-UI-V014.md)、[加载优化](docs/PERFORMANCE-V012.md)、[正文流式](docs/STREAMING-V011.md)。

## 从源码启动

建议使用 **Windows x64 + Node.js 24**；基础服务要求 Node.js 22.13+。先安装依赖：

```powershell
npm ci
npm start
```

打开 <http://127.0.0.1:4317/>。也可双击仓库中的 `start.cmd`。已有工作台占用端口时，请先退出旧实例。

启动 Electron 桌面窗口：

```powershell
npm run desktop
```

Electron 下载未完成时可运行 `node node_modules/electron/install.js`。桌面内置阅读与菜单能力；普通浏览器运行不等于所有桌面功能均可用。

## 配置模型

打开「模型与分工」，按功能选择连接：

- **API**：填写 Base URL、模型 ID 和 Key；当前直接 API 适配器支持 OpenAI 兼容 Chat Completions 与 function tools。
- **DSH / DeepSeek Harness**：先安装并配置 DSH。工作台自动查找 CLI 或 Desktop，也允许填写绝对路径。插件模型需要其插件与登录状态有效。
- **Codex / Claude Code**：安装对应宿主并完成配置，工作台按任务启动宿主，通过专属 MCP 写回。
- **手动 MCP**：由外部宿主领取消息并写回。MCP 本身不会自动唤醒宿主。

不同宿主使用各自的协议和能力。直接 API 连接不等于支持所有服务商原生协议。模型返回文字也不等于结构化提案已经保存：能力要求、路线、长期画像及新连接等提案仍需用户确认；已有连接的功能分工可直接设置。

DSH 会话由 AI Teacher 管理：同一站内对话复用同一 DSH 会话，多个对话共用学习工作区，日志与检查点按会话保存。这些 headless 会话目前不会自动出现在 DSH Desktop 的原生列表中。

参考：[DSH 配置](docs/DSH-HOST.md) · [持续会话与恢复](docs/DSH-SESSIONS-V09.md) · [功能分工](docs/AGENT-ORCHESTRATION.md) · [直接 API](docs/MODEL-ROUTING.md)。

## 数据与升级

- 开发环境默认数据目录为仓库的 `data/`；正式桌面包默认使用 `%APPDATA%\AI Teacher\data`。二者通常不是同一个学习库。
- 在「AI Teacher → 桌面设置」中查看或选择已有数据目录，也可使用 `--data-dir`。选择已有目录不会自动搬移或合并数据。
- 更新程序时，完整保留原数据目录；关闭旧窗口及其服务，再打开新版。不要只替换或搬走 EXE，整个成品文件夹共同构成应用。
- 完整备份应在退出应用后复制整个数据目录，或使用一致性 SQLite 备份。JSON 导出不包含全部附件与配置，不能代替完整备份。
- 学习数据库、密钥、Agent token、运行日志和实际生成的宿主配置均不应提交 Git；相关目录已列入 `.gitignore`。

本地成品沿用原库的启动示例：

```powershell
& ".\outputs\desktop-v0.18.0-release\AI Teacher-win32-x64\AI Teacher.exe" "--data-dir=$env:APPDATA\AI Teacher\data"
```

服务只监听本机，使用页面会话和独立 Agent 凭据区分权限。这是面向可信本机用户的应用，不是公网多用户服务。推理仍可能把当前任务所需内容发送给你选择的模型服务。

## 打包 Windows 桌面版

```powershell
$env:TEACHER_PACKAGE_OUT = "outputs/desktop-v0.18.0-release"
npm run desktop:package
```

成品入口为 `outputs/desktop-v0.18.0-release/AI Teacher-win32-x64/AI Teacher.exe`。打包携带执行构建的 Node 运行环境，需在 Windows x64 上构建；详细的许可证缓存、Electron 缓存与成品验证方法见 [桌面说明](docs/DESKTOP.md)。

目前没有安装向导、代码签名、自动更新、托盘或开机启动功能。桌面快捷方式需指向实际的新成品；源码版本、快捷方式目标和运行服务版本应分别核对。

## 验证

基础检查不使用真实学习库：

```powershell
npm run build
npm test
```

2026-11-10 的 V0.18.0 完整业务回归共 339 项通过。跨目标与教学流程可以用隔离库和本机固定回复模型重现；这不代表所有真实模型和教学效果均已验证。进一步验收按环境选择：

| 命令 | 验证范围 |
| --- | --- |
| `node scripts/smoke-desktop.mjs --canonical` | 两个学习目标、原回答引用、路线、复习、材料冲突与考察交互 |
| `node scripts/smoke-desktop.mjs --model-picker` | 五个对话入口、功能默认模型、刷新保留与窄窗口 |
| `node scripts/smoke-desktop.mjs --chat-ui` | 聊天排版、输入、草稿与滚动交互 |
| `node scripts/smoke-desktop.mjs --performance` | 单连接、通知合并、闲时请求与切换隔离 |
| `node scripts/smoke-desktop.mjs --streaming` | 真实 DSH + 本地模拟模型的正文流式、取消与续接 |
| `node scripts/smoke-dsh-local.mjs --plugin` | 非 Qoder 测试插件的真实 DSH 执行、模型切换与会话恢复 |
| `node scripts/smoke-dsh-registry.mjs` | 本机已安装 Qoder 的目录和执行适配器就绪；需要有效安装与登录 |
| `node scripts/smoke-desktop.mjs --registry` | 本机插件模型在真实桌面中的显示、选择和保存 |

DSH 联调需先安装本机 DSH；模拟执行使用临时配置和本地服务。注册表验收会读取本机提供商及插件配置，但不发送推理提示词。结果保存在本机 `outputs/`，不随源码上传。

成品验收先设置 `TEACHER_PACKAGE_DIR`，再给桌面 smoke 增加 `--packaged`。非桌面 DSH smoke 可通过 `TEACHER_DSH_APP_ROOT` 指向成品的 `resources/app`。不要同时构建和验收同一成品目录。

已验证目录、适配器就绪与本地模拟执行；未逐一验证所有云模型的付费推理、额度、教学质量或大型真实学习库性能。
